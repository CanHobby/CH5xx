# CH5xx

Sample Code for the CH582/3/5 etc Family of BLE MCUs

Written for the Moun River IDE - the zips include all of the required libs.

Create a separate dir on your coumputer and then unzip the .zip file into the dir.
- drill down until you find the *.wvproj file.
- double click on this file and Moun River should open the project.
